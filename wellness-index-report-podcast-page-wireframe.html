Contrast, for the build

Brand orange is text-safe on the navy and near-black grounds only. On light sections it works as shape rather than type: rules, fills, underlines, icons. Type on light grounds goes near-black.

ForegroundGroundRatioAA, normal text
#FF9500#09092A navy8.81:1passes
#FF9500#16191D near-black8.02:1passes
#FF9500#FFFFFF white2.20:1fails
#FF9500#FAFAF8 off-white2.10:1fails

Orange fails on light grounds at every text size, large text included, which needs only 3.0:1. No block in this wireframe indicates orange type; every ground here is drawn light gray, so no block is marked.

Form build constraints

  • Eight fields, one screen. Every input is plain except the repeating links field, the one item to confirm against the chosen builder.
  • An embedded third-party form in an iframe arrives with its own styling that page CSS cannot reach. A previous build hit exactly this with an embedded HubSpot form that duplicated the page's branding and could not be restyled from outside.
  • Inline, embedded iframe, modal, and separate page each change what P8 actually looks like. The inline version is drawn only so the block has a size and a place.
