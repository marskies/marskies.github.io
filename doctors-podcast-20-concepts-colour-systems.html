Colour system

Pink only: what it costs

Orange is the only thing connecting this show to Wellness Eternal. The brief asks the sub-brand to read as related, not identical. Remove the parent colour and there is no relation left, so this stops being a sub-brand and becomes a second brand. That is a real decision, not a palette preference, and it should be made out loud.

Rose is a weaker signal at thumbnail size. #FF9500 sits near the top of the visible saturation range at 55 px, which is why it holds in a crowded feed. #E9A3A9 is a pale tint that drifts toward neutral once it is small. Compare the two systems on the light-background chips before deciding.

Pink only runs two values, not one. A single light rose cannot do structural work: on the off-white editorial tiles it is nearly invisible. Deep rose #C75A6E takes anything sitting on a light field, light rose #E9A3A9 takes everything on dark. That two-step is what replaces the range orange was providing.

Positioning risk. Pink alone reads wellness-lifestyle, which is the register the brief steers away from given the physician guests and the no-BS line. Territory 4 is the only place pink only still reads as credentialed, because the editorial structure carries the seriousness instead of the colour.

The pink itself

Rose is #E9A3A9, not the sampled #F2B5AC. The existing cover's blush sits about 25 to 30 degrees from #FF9500 in hue and shares its warmth. Placed near the orange at thumbnail size the two stop reading as two colours. Rose is pulled cooler so the pair separates. In pink only this matters less, so the sampled blush is a live option there if Lindsay prefers it.

Pink can only survive at 55 px as an area. In the current cover it is a script line and a hand-drawn swash, both of which vanish first when the art shrinks. Where pink appears here it is a field, a band, a silhouette or a stroke with weight behind it.

Still true from the first pass

Territory 5 is not reviewable as drawn. The silhouettes are placeholders for Lindsay's press imagery. They show where a portrait sits, not whether one works. Her approval is required before any of it moves.

Three concepts fail the size test and are marked as such. They are kept because the failure is the argument: a full three-word serif name cannot hold at 55 px.

Name behaviour is tagged three ways. "Flexes" absorbs any of the four doctor spellings. "Doctor-locked" survives those four but dies if the show reverts to Optimize W(e). "Name-safe" does not reference the name at all.

If pink only is chosen, drop 07 and 10. 07 is built to live inside the parent brand's mark and recolouring that device defeats it. 10 loses too much contrast without the orange. Everything else survives, and 02, 09, 12 and 14 arguably improve.

One open question the colour does not settle. The pink in the current cover is carried by a script face that is not in the type system. If what Lindsay is attached to is the script rather than the hue, none of these will feel like continuity to her, and that is worth resolving before the shortlist.

Notes. All type is set with locked glyph widths, so compositions hold if Merriweather fails to load and when the name changes length. No gradients, stethoscopes, caducei or heartbeat lines. Every tile is flat and exports cleanly to 3000 × 3000. The 55 px renders are CSS pixels on this screen, which is a fair proxy but not a substitute for viewing the exported PNG on a phone.
